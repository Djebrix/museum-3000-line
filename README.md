One museum label a museum in the year 3000 puts beside an ordinary object from today — the CAPTCHA checkbox — written to `/output/entry.txt`.

Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
